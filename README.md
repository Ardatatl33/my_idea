# D-Plan Günlük İlerleme Prototipi

Bu proje, D-Plan Staj Programı Yazılım ve Ürün Geliştirme vaka çalışması
için Flutter ve Dart kullanılarak hazırlanmıştır.

## Amaç

Kullanıcının bugüne planladığı görevlerin ne kadarını tamamladığını tek
bakışta görebilmesini sağlayan küçük bir ürün iyileştirmesini göstermek.

## Özellikler

- Beş örnek günlük görev gösterir.
- Görev satırlarına dokunarak tamamlanma durumu değiştirilebilir.
- Tamamlanan görev sayısı ve yüzdesi otomatik hesaplanır.
- İlerleme çubuğu animasyonlu olarak güncellenir.
- Sıradaki tamamlanmamış görev gösterilir.
- Bütün görevler bittiğinde yüzde 100 mesajı gösterilir.
- Mobil ekran boyutlarına uyumlu tasarlanmıştır.

## Çalıştırma

Flutter kurulu bir ortamda proje klasöründe şu komutları çalıştırın:

```bash
flutter pub get
flutter run
```

## Test

```bash
flutter test
```
